---
name: project-checkpoint
description: Save a meaningful explicit development checkpoint and its evidence in Project Memory after tested or partial work.
---

Refresh Git and inspect the relevant diff/tool results. Separate completed, partial, failed and environment-blocked work; record actual test commands/results and remaining limits. Fetch scoped evidence and call project_create_checkpoint with title, concise summary, nextActions and evidenceRefs. A checkpoint is explicit testimony, not verified proof of a feature. Update semantic state only with current scoped evidence and expected revision. Do not copy hidden reasoning or secrets.
